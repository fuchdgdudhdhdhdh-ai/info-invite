# Telegram Invite Bot

Бот для отслеживания статистики по одной пригласительной ссылке в группе.

## Возможности
- Учёт заявок на вступление
- Учёт вступлений
- Учёт выходов
- Активные участники
- Команда `/stats`

## Деплой на Render

1. Залейте проект в репозиторий GitHub.
2. В Render создайте **Web Service**, подключите репозиторий.
3. Добавьте переменную окружения `BOT_TOKEN` (токен от @BotFather).
4. Render автоматически использует `RENDER_EXTERNAL_URL` для вебхука.
5. После деплоя добавьте бота в группу администратором с правом **«Приглашать пользователей»**.
6. Отправьте в группе команду `/setlink <ваша_ссылка>`.
7. Проверьте статистику командой `/stats`.

## Важно
- Бот должен быть администратором группы.
- Файл SQLite (`bot_stats.db`) на бесплатном тарифе Render может сбрасываться при перезапуске. Для постоянного хранения используйте Render Disk или внешнюю БД.
